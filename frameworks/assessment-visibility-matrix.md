# Assessment Visibility Matrix

The Assessment Visibility Matrix is a framework for examining how clearly a task makes human thinking visible.

It begins with a central problem:

> When artificial intelligence can produce a polished artifact, the artifact alone may no longer provide sufficient evidence of human capability.

## Purpose

The matrix helps educators, leaders, and organizations evaluate whether a task reveals:

- problem framing
- reasoning
- decision-making
- interpretation
- revision
- verification
- application
- human judgment

## Core Question

Instead of asking only:

> What did the person produce?

the matrix asks:

> What parts of the person's thinking can we actually observe?

## Visibility Levels

### Low Visibility

The final artifact is visible, but the reasoning behind it is largely hidden.

Examples:

- generic written reports
- unsupervised take-home essays
- polished slide decks
- AI-generated summaries
- completed templates without explanation

### Partial Visibility

Some thinking is visible, but important decisions or revisions remain hidden.

Examples:

- annotated drafts
- reflection statements
- source notes
- prompt histories
- revision explanations

### High Visibility

The task makes reasoning, judgment, and adaptation directly observable.

Examples:

- live demonstrations
- oral defenses
- applied problem-solving
- iterative feedback conversations
- scenario-based decisions
- process documentation
- authentic performance tasks

## Design Principle

The goal is not to eliminate AI.

The goal is to design work in which meaningful human contribution remains visible.

## Applications

The framework can support:

- assessment redesign
- employee evaluation
- AI use policies
- portfolio design
- hiring processes
- professional learning
- performance reviews
- organizational decision-making
